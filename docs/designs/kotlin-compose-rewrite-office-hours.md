## Problem Statement
App Java 17 Swing 25k LOC, libs cũ (Rhino, Selenium, 2 JSON libs, 2 HTTP clients, JUnit 4), 534 checkstyle violations legacy. Maintain khó, không có đường sang mobile. Owner muốn bỏ hẳn Java, rewrite Kotlin + Compose Multiplatform: desktop → Android → iOS (lazy) + wasm preview để QA UI. Tài sản đáng giá nhất: **sinh thái plugin JS** (API Engine/Browser/Html/Http/Json/Text/Regexp/LocalStorage/UserAgent/Response + loaders Detail/List/Text/Page + vBooks compat).

## What Makes This Cool
Một engine plugin JS chạy trên 4 platform từ một codebase Kotlin; wasm preview cho QA UI bằng script Playwright không đốt token. Hướng "plugin forge" (AI sinh plugin tự động, E2E harness làm judge) nằm ở backlog — lợi dụng đúng tài sản đã có.

## Constraints
- Solo developer, AI-assisted (Claude gõ gần hết) → đo plan bằng "ít code mới nhất giữa API frozen và app chạy được".
- Rhino JVM-only: desktop + Android OK; iOS cần QuickJS (quickjs-kt), wasm dùng browser JS.
- **Rhino thread-affinity (eng review 1A)**: mọi script-call chạy trong `engineDispatcher` confined (parallelism = context pool size), `Context.enter()/exit()` gọn trong 1 hàm duy nhất — coroutines không nhảy thread giữa script-call. Test download 5 chapter song song từ slice.
- **Package rename khi port (eng review 4A + owner)**: `dark.leech.text` → `dev.haipham22.leechtext`; `enities` → `entities`. An toàn cho plugin: sandbox expose JS API objects qua JsApiSetup, không importPackage.
- **Serialization (eng review 2A-sửa)**: Gson giữ P1-P3 (JVM + Android); kotlinx.serialization swap = **task đầu tiên của P4** (Gson cần reflection, không chạy wasm); FormatCompatTest chạy lại sau swap.
- **wasm seam risk (P4 entry gate)**: Html.parse cần ksoup (jsoup không chạy wasm) — ksoup không đủ thì CUT wasm, QA UI chuyển Compose Desktop screenshot-diff. wasm/iOS không có filesystem phẳng: Storage actual per-platform quyết ở P4.
- **Browser API (Selenium) desktop-only**: platform khác (Android/wasm/iOS) throw lỗi rõ "Browser API desktop-only" — plugin cần browser không chạy được ngoài desktop, đó là degrade có chủ đích.
- Không Apple Dev account → iOS không có kênh phát hành, deprioritize.
- Persistence format cũ (setting.json, properties.json, .plugin zip) phải đọc được — **FormatCompatTest với fixture data thật từ app Java cũ là gate** (eng review 5A), fixture capture trước khi xoá `src/main/java`.

## Premises (đã confirm)
1. **Toàn bộ `plugin/js/api/**` frozen** (Engine, Browser, Html, Http, Json, Text, Regexp, LocalStorage, UserAgent, Response, Num, Core, Consumer...) — contract là 12 test file trong `src/test/java/dark/leech/text/` (9 plugin: 3 api + 4 loader + 2 vbook; 2 util; 1 action/export) port sang Kotlin. Không đổi chữ ký.
2. Parity gate **tiered** thay vì 100%: MUST (download/export/plugin manager) / NICE / CUT (plugin editor đã CUT, rsyntaxtextarea dep chết theo). Mục nào không làm ở platform khác phải đánh dấu "desktop-only/degrade có chủ đích" kèm lý do — đó vẫn tính là đạt gate. Checklist được Claude draft, owner duyệt tier assignment trước khi P2 bắt đầu.
3. Desktop Compose trước, Android sau — de-risk engine trước khi mobile.
4. Distribution: APK sign + GitHub Releases (không Play Store, không F-Droid, không Apple).

- iOS seam: [quickjs-kt](https://github.com/quickjs-kt/quickjs-kt) (KMP JVM/iOS/macOS, không wasm — browser-JS fallback đứng nguyên).
- Weekend build: port sandbox + 3 E2E test + mini window tải 1 chapter → xác minh rủi ro lớn nhất trong 1 cuối tuần.

## Approaches Considered
### Approach A: Plan gốc — port toàn bộ engine (1-2 tuần) rồi mới UI
Effort L, risk Med: sai phạm Rhino sandbox phát hiện muộn sau khi port 10k LOC. Bị loại vì rủi ro phát hiện trễ.
### Approach B: Vertical slice trước rồi mở rộng theo P1-P4 (CHỌN, sửa theo eng review + outside voice #6)
Effort S (human ~2 ngày / CC vài giờ). Port `JsSandbox` + `RhinoContextPool` + `Response` + API `Http`, `Html`, `Text`, **`Json`, `Regexp`** (vbook E2E exercise Json.parse — thiếu là đỏ oan) + @Test E2E từ 2 file `plugin/vbook/` (plugin script + fixture nguyên văn, assertion exact-match, pin Rhino 1.7.15) + mini Compose window. **Chapter fetch qua fixture HTML lưu sẵn** (live site = optional smoke, không chặn gate — tránh phụ thuộc uptime/Cloudflare site thật). Green → mở rộng nguyên P1-P4.
### Approach C: Legado-style headless core (Ktor server + thin clients)
Effort XL, risk High — kiến trúc đẹp nhưng mâu thuẫn "ship nhanh thắng architecture". Bị loại.

## Recommended Approach
**B**. Bảo hiểm rẻ nhất cho rủi ro lớn nhất (Rhino sandbox port), không đổi đích đến. Slice green trong 1 cuối tuần → toàn bộ plan còn lại đứng vững; đỏ → biết giá thật sau 2 ngày thay vì 2 tuần.
